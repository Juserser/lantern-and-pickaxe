# 🏮⛏️ 등불과 곡괭이

둘이 함께 파 내려가는 아기자기한 2인 협동 로그라이크.

- **한 키보드로 둘이** 또는 **온라인 방 코드로 각자 기기에서** 실시간 플레이
- 조작: 1P `WASD` + `C` 공격 / `V` 스킬 / `B` 합동기 / `E` 신호 · 2P `방향키` + `.` / `/` / `,` / `'` · `Esc` 일시정지 · `M` 미니맵
- 신호 키를 방향키와 같이 누르면 감정표현 (↑ 도와줘 · ↓ 잠깐 · ← ㅋㅋㅋ · → 최고야)
- 설치 없이 `index.html` 을 열거나 배포 주소로 접속

## 원정 문에서 고르는 모드
- 🏮 **원정** — 별빛 단계로 난이도 조절
- 🌙 **깊은 밤** — 저주 9종을 골라 켜요. 저주 단계가 높을수록 광석·별조각 보상 증가
- 📅 **오늘의 동굴** / 🗓️ **이번 주 도전** (주마다 규칙이 바뀜, 6층 도달 시 별조각)
- 👑 **보스 러시** — 보스 4마리 연속, 기록 경쟁
- 출발 전에 둘이 각자 **캐릭터 선택** (🐰 토토 · ⛏️ 몰리 · 💣 냥폭 · 🛡️ 꼬북 · 🦊 여울 · 🍙 도토 · 🦉 후후 · 🐧 뽀롱)
